## 🏗️ Technical Migration Overview
This repository serves as a high-performance bridge for legacy traffic. I have migrated my primary portfolio from a monolithic GitHub Pages deployment to a modern **Headless Architecture** hosted on **Vercel**.

### **Why the Migration?**
* **Edge Delivery:** Leveraging Vercel’s global edge network for sub-second load times in the KSA region.
* **Serverless Logic:** Enhanced capabilities for handling Odoo XML-RPC integrations and real-time data orchestration.
* **Architecture-First:** Shifted to a unified React/Next.js and TypeScript codebase for enterprise-grade scalability.
